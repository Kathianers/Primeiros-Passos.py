# 🐍 Exercícios Iniciais de Python - ADS

Repositório dedicado aos primeiros códigos e listas de exercícios desenvolvidos em **Python** durante o início da faculdade.

---

## 📋 Atividade - Lista de Exercícios com IFs

👩‍💻 EX01: Sistema de votação para definição do melhor dia da semana para realização de lives (com validação de empate);

👩‍💻 EX02: Simulador de compra parcelada de veículo, exibindo o preço à vista com desconto de 20% e uma tabela com a quantidade de parcelas (de 6x a 60x), o preço final corrigido com os acréscimos e o valor de cada parcela.

👩‍💻 EX03: Simulador de crédito para clientes de uma fintech, gerando uma tabela via estrutura de repetição que detalha o valor total da dívida, o valor dos juros aplicados, a quantidade de parcelas e o valor de cada parcela do empréstimo.

👩‍💻 EX04: Simulador de resgate de investimentos de renda fixa (CDB, LCI e LCA) com validação de tipo, cálculo de Imposto de Renda regressivo baseado nos dias aplicados para CDB, e verificação de isenção para LCI e LCA.
